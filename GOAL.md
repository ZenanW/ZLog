# North Star

**Dev cycle: Practice.** Ship a **Practice** tab (sibling of Lectures and Exams) where a user picks a backlog lecture that has imported slides and gets a persisted set of **multiple-choice** and **short-answer** questions generated by Claude from that PDF. It is DONE when a user can:

1. Open **Practice**, pick a lecture via a subject → lecture picker. Lectures without a `lecture_slides` PDF are clearly blocked (“upload slides first”).
2. Press **Generate** — Claude returns structured MCQs + short-answer items grounded in the slides. Results persist and **replace** the previous set for that lecture.
3. **Practice** the set in the UI: select an MCQ option or type a short answer, then reveal correctness plus a short explanation / slide cue.
4. Regenerate or delete a set. Semester reset wipes practice data.

Previous cycle (Notes — editor, Cornell, images, AI note evaluation, external notes import) is **ABANDONED**. Do not keep, extend, or regress into note-taking. Previous cycle (AI PDF analysis + editorial UI overhaul) is SHIPPED and ACCEPTED — do not regress lectures, exams, or slide analysis.

- **Explicitly OUT OF SCOPE this cycle:** note-taking, Google OAuth / Google Docs, collaborative editing, live/as-you-type AI, generating questions from exam topics only (slides are the source of truth), spaced-repetition / Anki export, a second Claude call to grade short answers. - **Do NOT commit.** Never run `git commit`, `git push`, or alter git history. The user commits. Leave changes in the working tree.

## Feature Spec

### Data model

Future migration `007_practice_questions.sql` (not written until the Foundation backlog item):

`practice_sets`:

- `id uuid primary key`
- `user_id text not null`
- `lecture_id uuid not null references lectures(id) on delete cascade`
- unique `(user_id, lecture_id)` — one current set per lecture; Generate replaces it
- `generated_at timestamptz not null`
- `created_at` / `updated_at timestamptz not null default now()`

`practice_questions`:

- `id uuid primary key`
- `set_id uuid not null references practice_sets(id) on delete cascade`
- `sort_order integer not null`
- `kind text not null` — `mcq | short`
- `prompt text not null`
- `choices jsonb` — MCQ: `[{ id, text }]`; null for short
- `correct_choice_id text` — MCQ only
- `model_answer text` — short-answer only
- `explanation text not null`
- `slide_reference text`

Client types `PracticeSet` / `PracticeQuestion` in `src/lib/types.ts` mirror this in camelCase.

### Generate defaults

- **6 MCQ + 3 short-answer** per set (tunable later; do not bikeshed).
- Each MCQ has **4 choices**, exactly one correct (`correct_choice_id`).
- Short-answer grading this cycle is **self-reveal** against `model_answer` + `explanation` — no second Claude call.

### Practice tab

- New top-level tab in `AppShell` (sibling of Lectures and Exams). Primary surface — lecture cards may later get a “Practice” jump (Polish).
- Subject → lecture picker (`LecturePicker`). Lectures without `lecture_slides` cannot generate; UI says to upload slides on the lecture first.
- Generate / regenerate / delete the set for the selected lecture.
- Session UI: MCQ tap-to-select, short-answer text field, then reveal correctness, explanation, and slide cue.

### API (Foundation / Generate items)

- `GET /api/practice` — list sets for the user (include questions).
- `DELETE /api/practice/[id]` — delete a set.
- `POST /api/practice/generate` body `{ lectureId }` — download that lecture’s latest `lecture_slides` PDF, send it as the first document block, structured output matching the question schema, persist (replace existing set for that lecture), return the mapped set.

### Semester reset

`DELETE /api/backlog` must wipe `practice_questions` / `practice_sets` for the user (Polish if not done in Foundation). Must not reference `notes`.
